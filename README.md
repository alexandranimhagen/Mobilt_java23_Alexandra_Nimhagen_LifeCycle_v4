Mobile Flutter App – Lifecycle & State (Flutter v4)

A Flutter mobile app showcasing widget lifecycle, state management, and UI responsiveness. Part of a Java YH-course, this project demonstrates how to handle app state and widget rebuilds effectively.

Features

- Demonstrates Flutter widget lifecycle methods  
- Manages state using `StatefulWidgets` and `setState()`  
- Tracks and displays lifecycle changes in real time  
- UI with buttons or switches to trigger rebuilds and state updates  
- Ensures responsive, reactive behavior across mobile platforms

Technologies Used

- Flutter & Dart  
- Widget lifecycle methods (`initState`, `dispose`, etc.)  
- State management via State/Provider  
- Android & iOS compatibility
